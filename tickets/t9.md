## Summary

mise run new -- agentic-agile-deguboard で記事を作り、本文を書く。構成案は会話で合意済みのため、この工程に含める。AI コーディングで新しい種類の負債に苦しんでいる → さまざまな開発の進め方が提唱されている → その一つが Agentic-Agile → 実践するツールとして deguboard を作った、という流れにする。deguboard の細かい使い方は2本目（e3）に回す。

構成:
1. はじめに: AI コーディングが生む新しい負債（書き手の困りごととして。判断の経緯が会話の中で消える／レビューしきれない変更が積み上がる／進み具合や誰が何を決めたかが見えない）
2. 世の中の動き: 仕様駆動開発など、さまざまな進め方が提唱されている。網羅はせず、その一つとして Agentic-Agile を位置づける
3. Agentic-Agile とは: 提唱者と出典、定義、主な考え方を3つ程度。1の負債にどう効くかを結びつける
4. 実践しようとすると困ること → deguboard を作った動機
5. deguboard の紹介: 役割分担、特徴（Git の deguboard ブランチ、--actor、人間だけの操作、Run、Claude Code の Skill、VS Code の画面）、開発の流れの概観
6. まとめ、入手方法、次回の予告
