## Summary

slug を YYYYMMDD-topic 形式にし、brainpad Publication 向けの frontmatter を持つ記事の雛形を 1 コマンドで作れるようにする。

## Acceptance criteria

- [ ] npm run new:article -- <topic> で articles/YYYYMMDD-<topic>.md ができる
- [ ] 生成した記事の frontmatter が publication_name brainpad と published false になっている
- [ ] Zenn の slug 制約（a-z0-9-_、12〜50 文字）を満たさない topic ではエラーになり、ファイルを作らない
- [ ] 記事と同時に images/<slug>/ ができる
