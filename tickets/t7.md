## Summary

人も AI も CI も、プレビュー・記事作成・lint を mise run <タスク> で実行できるようにし、コマンドの入口を mise にそろえる。npm scripts を直接呼ぶ手順をなくす。

## Acceptance criteria

- [x] mise run preview でプレビューが起動する
- [x] mise run new -- <topic> で t2 と同じ記事と画像フォルダができる
- [x] mise run lint で textlint と markdownlint の両方が実行される
- [x] mise tasks で各タスクが説明付きで一覧に出る
- [x] CI の lint ジョブが mise run lint を実行する
- [x] dg の actions.test が mise run lint になっている
