## Summary

人も AI も CI も、プレビュー・記事作成・lint を mise run <タスク> で実行できるようにし、コマンドの入口を mise にそろえる。npm scripts を直接呼ぶ手順をなくす。

## Acceptance criteria

- [ ] mise run preview でプレビューが起動する
- [ ] mise run new -- <topic> で t2 と同じ記事と画像フォルダができる
- [ ] mise run lint で textlint と markdownlint の両方が実行される
- [ ] mise tasks で各タスクが説明付きで一覧に出る
- [ ] CI の lint ジョブが mise run lint を実行する
- [ ] dg の actions.test が mise run lint になっている
